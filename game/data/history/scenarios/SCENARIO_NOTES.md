# 剧本设定与史料边界

本目录的剧本是面向策略地图的「时点快照」，不是逐郡复原。地图只有有限的城市/关隘/渡口节点，控制范围会被压缩到这些节点；人物驻地、军团兵力与城池资源是游戏化起始参数，不应被理解为史书中的精确编制或逐日驻防记录。

## 当前剧本

- `190_coalition.json`：初平元年讨董局势。纳入董卓、曹操、袁绍、袁术、孙坚、公孙瓒、刘虞、韩馥、陶谦、孔融、刘表、刘焉、刘岱、马腾、韩遂、公孙度等主要割据者。刘备仍作为公孙瓒阵营中的人物处理；张鲁尚未作为独立势力，列入刘焉体系，避免把其脱离刘璋的阶段提前到 190 年。
- `200_guandu.json`：官渡战前后势力快照。袁术已不再作为独立势力；刘璋、张鲁、马腾、韩遂与公孙度补入可见势力。益州、汉中、凉州和辽东不再被笼统标成无主地。
- `208_red_cliffs.json`：开局设为建安十三年秋、刘表病逝与荆州易手之后。刘备在夏口，孙权以柴桑为前线；辽东由公孙度之子公孙康承继；刘璋、张鲁及荆南四郡仍保有独立据点。荆南四个郡级势力用于表达赤壁前后尚未完成的地方整合。

## 来源与校订原则

人物与关键归属优先核对《三国志》《后汉书》传记；游戏人物能力仍来自现有参考数据文件，并非本目录的史料结论。遇到日期或地方控制有争议时，采用剧本简介中的时点口径，并把地理节点标为战略近似。新增/调整的重要人物归属应同步更新本文件和对应场景测试。

可查阅的传记底本：

- [《三国志·袁术传》](https://ctext.org/text.pl?if=gb&node=602248&remap=gb)：董卓之乱时袁术出奔南阳，并与袁绍、刘表等势力存在联盟与冲突关系。
- [《三国志·袁绍传》](https://ctext.org/text.pl?if=gb&node=602234)：官渡前后的袁曹关系与战局。
- [《三国志·刘焉传（子璋）》](https://ctext.org/text.pl?if=gb&node=603390&remap=gb)：刘焉入益州、刘璋继任及益州势力沿革。
- [《三国志·张鲁传》](https://ctext.org/text.pl?if=gb&node=602324&remap=gb)：张鲁先受刘焉任用，后在刘璋时期据汉中自立；因此两个剧本采用不同归属。
- [《三国志·公孙度传》](https://ctext.org/text.pl?if=gb&node=602310&remap=gb)：辽东公孙氏的根据地及公孙度去世后由公孙康承继。
- [《后汉书·刘虞、公孙瓒、陶谦列传》](https://ctext.org/hou-han-shu/liu-yu-gong-sun-zan-tao/ens)：幽州与徐州主要人物的关系和势力背景。
- [《三国志·先主传》](https://ctext.org/text.pl?if=gb&node=603400)：长坂之后刘备与刘琦部众会合、驻至夏口等赤壁前背景。
- [《后汉书·董卓列传》](https://ctext.org/text.pl?if=en&node=76692&remap=gb)：董卓与韩遂、马腾及关中局势。

## 后续待核

- 为地图补入更多有史据的州郡节点时，同时校验道路双向连接、坐标占用和各剧本的所有权映射。
- 208 年荆南诸郡的主将名单需要逐一与《三国志》相关传记核对；不要把《三国演义》中的戏剧化对阵或虚构人物直接写成史实。
- 184 年黄巾剧本尚未建立；新增时应与 190 年剧本区分人物出场年份、黄巾军与汉廷阵营，而不是复制后改标题。
