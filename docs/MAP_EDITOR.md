# 舆图编辑器

## 海陆定稿约束

用户已于2026-10-11完成陆地、海洋和海岸线编辑。后续维护以用户最新保存或导出的地形层为准，不自动缝补、平滑或重建海岸线，也不以旧像素底图、掩码或归档替换陆海格。州郡、道路、河流与据点应适配这份地形；出现冲突先报告，不通过修改海陆消除问题。用户自己在编辑器中主动修改地形的能力不受影响。

浏览器中的定稿不等于仓库默认地图已更新；接入项目基准需要取得完整地图导出并核对。以下扩格、还原与重建说明仅描述可用工具，不代表允许对定稿自动执行；开发时先检查生成器是否会回读旧归档、覆盖地形。

## 当前使用方式

进入游戏中的编辑器会暂停模拟。顶部控制缩放与拖动，右侧按「地形 / 州域 / 郡域 / 据点 / 道路 / 河流」切换工具；州域只读查看，通过「调整郡属州」分配整郡，不再单独绘制州界。右栏底部的撤销、重做、校验和应用不随表单滚动。最大化与普通窗口使用相同的布局，窄窗口自动上下排列。

默认地图为100×100。旧60×60战局和已保存的手绘图不会自动扩格；在「地图网格」中两次点击「转换为100×100」确认，可将当前编辑内容同步映射。地形、州郡按格中心取样，城市、县治、郡治与河流、地标同步换算，道路补齐正交中间格，节点ID、势力、人口和资源不变。整次转换只占一条撤销记录；保存剧本或应用战局后才持久生效，未保存的转换可随编辑草稿恢复。进行中的道路、河流与未保存表单需先完成或取消。

参考底图的位移以新旧尺寸比换算，等比例扩格不改变底图缩放、不透明度及相对位置；撤销、重做与跨尺寸导入同步配准。完整地图补丁可跨尺寸回读，不完整的跨尺寸分层仍拒绝导入。距离按原网格尺度折算，不把网格细化当作国土面积扩大。

- 图层笔刷支持地形、郡域，宽度为 1 / 3 / 5 格；Alt 点击地图可取值。郡域笔刷、连片改属和整层填充都跳过海面。快速拖动会补齐途经格子，每一笔只占一条撤销记录。
- 「参考底图」支持 PNG、JPG、WebP、BMP（最大64 MB）。添加后保持比例居中，默认锁定；可调整0～100%不透明度（0为全透明）、10～1000%缩放及以网格为单位的横纵位置。点击「调整底图」后左键拖动、普通滚轮以光标为锚缩放底图；点击「完成调整」或切换地图工具后锁定，再描绘州郡。Ctrl滚轮仍缩放整个视口，空格/中键仍平移视口；Esc取消正在进行的底图拖动并锁定，不删除地图编辑。网格、边界和节点始终叠在参考图上方。
- 郡域工具中，点击可见县治或城市即可选中它所在的郡；「点选郡域」可从任意已有郡域格取值，不改地图。随后左键点击或拖动添加，右键将笔刷覆盖的陆地格随机归给上下左右接壤的其他郡（候选郡去重、等概率，不删除县治或城池）；没有邻郡可接替时保留原归属，不产生黑色空格。宽笔刷从接壤处向内部接替，同一笔触中每格至多改一次，重复覆盖不反复随机。Shift 左键可直接改节点所在格，连片填充开启时仍按左键填充操作。右键始终按笔刷宽度，不进行整片清空，其他工具与平移模式的右键不会绘制。整笔可撤销；重做与保存保留已选定的邻郡，不重新随机。
- 地形和郡域是独立可编辑图层，州域是郡域的派生层。海面清除州郡归属，已有陆地郡界不重画；未划定陆地优先沿陆地邻接补到已有郡，新孤岛按最近已有郡域归属。州域由「郡 → 州」关系自动合成，同一郡的所有陆地格属于同一州。州域模式点击地图可选郡；州域或郡域面板选择郡、所属州后点击「调整郡属州」，州界和节点州属一起更新，可撤销。新郡初次绘制继承落笔处州属，随后可整郡调整。州界、郡界仍可独立勾选叠加到其他工具中。
- 城市、县治及地图郡治节点的州郡归属由所在坐标决定，绘制、填充、还原边界、移动城市、导入地图时自动更新；无需额外同步按钮。据点表单的州郡只读，修改坐标时显示对应归属。撤销边界或移动操作时，节点归属一起还原；打开编辑器本身不修改正在游玩的战局。
- 点击据点只选择；按「移动据点」后点击空格安置，Esc 取消。定位按钮将视口移到当前据点。关联县治和郡治的坐标会一起调整，失效的道路要求重新绘制。
- 道路从所选起点逐格绘制到终点。可点击相邻格或按住拖动；沿末端返回上一格可以撤回，Ctrl/⌘ Z 可撤销路径点。途经海面及自身绕圈会被拦截，端点改变会取消旧路径草稿。
- 道路列表包含城市与县治等节点的道路，地图点击路径也可选中。可重画，或按「调整节点」拖动中间控制点，邻接路段会补齐正交网格；端点仍固定在节点坐标。删除所选城市道路同步移除通行关系，「清空全部道路」同时清空路径与城市接边，不会自动重建。
- 河流是独立的路径图层，不会涂改底层地形。可选中、命名、新绘、重画、拖动控制点，或删除所选控制点、单条河流、全部河流；允许河口延伸到海面。新绘时可点击落点或按住拖动描线，至少两个点后完成保存。
- 河流沿格子边线走：新绘、重画和拖动控制点都吸附到最近的格子角点，相邻控制点之间自动补成沿格线的台阶，可停在网格四周边界上。地图数据中以 `anchor:"corner"` 标记；未带此标记的旧存档河流仍按格心折线显示和编辑，改名或拖动不改变其坐标含义。
- 删除所选道路或河流是一键操作，可撤销；地图获得焦点后 Delete / Backspace 也可删除所选路径。批量清空仍需要五秒内再次点击确认。河流草稿与道路草稿互斥，未完成路径会阻止应用、导出和据点移动。
- Ctrl/⌘ Z 撤销，Ctrl/⌘ Shift Z 或 Ctrl Y 重做；文本框中保留原生文本撤销。空格加左键或中键拖动地图，Ctrl 滚轮以光标位置缩放，视口缩放范围为50～800%。适配同时考虑可视区域宽度和高度。
- 整层填充、还原图层、删除据点、清空全部道路或河流需要在五秒内再次点击确认，并且都可撤销。

## 保存与数据约定

参考图及其位置保存在浏览器独立的 `sanguo-map-reference` 数据库中，按剧本、地图和战局槽位隔离；刷新后恢复，调整模式不自动恢复。图片原件与小型位置记录分别保存，平移不重写图片。每次载入解码原图并生成可选的2048像素长边预览，拖动不重复解码；缩小时使用预览，放大超出预览分辨率时直接读取原图。底图独立于固定分辨率的网格画布，按设备像素比绘制当前可见区域，不分配整幅放大画布；平移、视口缩放与窗口大小变化刷新可见裁切。参考图不进入地图补丁、剧本地图或游戏存档；换设备需要重新添加图片。替换或移除写入失败时保留旧图；浏览器没有IndexedDB时仅保留本次会话，明确显示提示。

编辑内容先保存在编辑器里，应用后才写入当前战局或所选剧本。进行中的道路、河流和未保存的据点表单会阻止应用与导出，避免产生看似成功但缺少最后一步的结果。

开始界面的「保存剧本」把当前地图保存到浏览器的独立 IndexedDB 数据库，按剧本隔离；刷新页面、切换剧本或新开局时自动使用。右栏可「载入已保存地图」或「恢复原始地图」；替换未保存编辑和恢复原始版本需要再次点击确认。恢复原始会移除已保存版本，仍可撤销并重新保存。写入或删除失败时不会先替换当前地图；原始项目文件不被覆盖，跨浏览器、设备或访问地址请导出补丁备份。原始剧本发生变化时不自动套用旧地图，需在编辑器中手动载入并核对。

进入战局后的「应用并保存」只修改当前战局的存档，不覆盖开始界面的剧本地图。已有战局继续使用自己的地图；旧存档没有编辑扩展时使用原始剧本，不受后来保存的自定义剧本地图影响。同页切换存档时，地图网格、道路、河流及地标均重新读取，不残留上一局的显示缓存。

每个剧本、地图及存档槽位有独立草稿。草稿使用 IndexedDB，不与 localStorage 中的大型战局副本竞争容量；兼容读取旧的 localStorage 草稿。草稿会恢复尚未应用的图层、城市资料、道路与河流绘制；未完成路径恢复后自动进入对应工具。如果源地图已经变化，则显示恢复 / 放弃旧草稿入口。

战局存档新增可选的 `world.mapEditor` 扩展，不改变旧存档版本。它记录编辑后的地图与行政资料，并保留城市改名、移动和删除。没有该扩展的旧存档仍按原有的历史数据迁移方式加载，防止旧地图坐标覆盖新剧本。

地图补丁与完整剧本均包含地形、州郡、道路、县治和行政资料。导入先在独立副本中解析并校验，再一次性写入；格式错误、不完整的跨尺寸地图、坏路径等失败不会改变当前编辑或消耗撤销。明确的空道路、水道、地标列表表示清空，不能悄悄重新生成默认数据。跨尺寸回读要求全部地形、州郡、城市、县治、行政资料和通行图，尺寸范围4～256格；编辑器的扩格入口仅转换为100×100。

郡属州持久化为`map.commandery_provinces`，`map.provinces`保留派生快照以兼容旧工具。旧地图缺少对应关系时从行政治所声明与原州域推导；显式郡属州优先，旧州格不能反向覆盖它。旧剧本地图和草稿的基准指纹保持兼容，不因行政层升级退回默认地图。裁切和自动合成只改变行政层，不改地形、海陆掩码、节点坐标、道路或人口；海面上的节点与道路仍由校验报告，不自动搬迁或填海。

地图补丁文件不是可直接安装的模组压缩包；完整模组打包仍需独立的 manifest 和补丁文件。

原始剧本使用用户2026-10-11定稿的100×100手绘地形，119个郡国及其治所由该地形重推落格。界线控制资料、概化范围和重建命令见 `docs/MAP_SOURCES.md`。新开局使用该定稿基准；此前战局按归档地图恢复，自定义剧本和编辑战局不自动替换。原始60格、校正60格、105郡国100格、119郡国100格四个历史版次通过存档的 `world.mapRevision` 区分；`world.mapEditor` 中的玩家编辑地图不受默认尺寸限制，仍优先。

## 地形细化（2026-10-14）

陆地地形按《三国志》全地名分布地图（`output/ref/quandiming.jpg`，未入库）逐格重估：先以海陆轮廓把底图配准到 100×100 网格（98% 格一致），再按每格的高程色带与起伏度定地形，海陆格、海岸线、河流、道路与据点坐标均未改动。

- 新增地形「高平地」（highland）：海拔高而地面平坦，如河套、河西走廊、上党、云南坝子。行军同平原，野径略慢，守御 +5%，补给 0.55，骑兵 ×1.12。
- 起伏大的中高地为丘陵或山地，高处中等起伏为高原（黄土高原、云贵），极高处为高原；底图为湖面的内陆格为泽地。原有泽地、荒漠、草原、林地、盆地在高程相符处保留。
- 据点格取周边九格中最平坦的地形（关隘除外），城邑落在谷地；渭水两侧按河道改为渭河平原，以免底图的秦岭色带压到关中。
- 路网按沿线地形核对，9 条改类：上谷道、巴郡道（涪陵—江州、永安—巴东）、阴平道、青衣道改山道；雒县—绵竹、蓟—昌平、武威二县道改道路。玄菟道、徐无、雁门道、庐江道、郁林道按史保留。
- 以后改动地形或路网后可运行 `node tools/audit-terrain-roads.mjs` 只读复核。

## 人物扩充兼容（2026-10-15）

人物开局分驻可能改变基准据点的太守字段。此轮为四个受影响剧本记录已验证的旧基准指纹，仅在对应新版基线下兼容，不放宽其他底图变更的检查。已保存地图缺少新增人物配置的据点时，只把新增人物/新增分驻寄置到现有本郡或本方据点，不重建任何地图节点、地形、道路或区划。战局旧档新增人物也只在存档现有据点内安置，存档已有的人物、任免与地图优先。
