# 舆图编辑器

## 当前使用方式

进入游戏中的编辑器会暂停模拟。顶部控制缩放与拖动，右侧按「地形 / 州域 / 郡域 / 据点 / 道路 / 河流」切换工具；右栏底部的撤销、重做、校验和应用不随表单滚动。最大化与普通窗口使用相同的布局，窄窗口自动上下排列。

- 图层笔刷支持地形、州域、郡域，宽度为 1 / 3 / 5 格；Alt 点击地图可取值。快速拖动会补齐途经格子，每一笔只占一条撤销记录。
- 地形、州域、郡域使用独立网格图层，各自绘制不会覆盖其他层。州郡边界由区域网格自动生成，可加入新名称，或勾选「点击改整片相连区域」调整相连的同名区域。州界、郡界还能独立勾选叠加到其他工具中。
- 城市、县治及地图郡治节点的州郡归属由所在坐标决定，绘制、填充、还原边界、移动城市、导入地图时自动更新；无需额外同步按钮。据点表单的州郡只读，修改坐标时显示对应归属。撤销边界或移动操作时，节点归属一起还原；打开编辑器本身不修改正在游玩的战局。
- 点击据点只选择；按「移动据点」后点击空格安置，Esc 取消。定位按钮将视口移到当前据点。关联县治和郡治的坐标会一起调整，失效的道路要求重新绘制。
- 道路从所选起点逐格绘制到终点。可点击相邻格或按住拖动；沿末端返回上一格可以撤回，Ctrl/⌘ Z 可撤销路径点。途经海面及自身绕圈会被拦截，端点改变会取消旧路径草稿。
- 道路列表包含城市与县治等节点的道路，地图点击路径也可选中。可重画，或按「调整节点」拖动中间控制点，邻接路段会补齐正交网格；端点仍固定在节点坐标。删除所选城市道路同步移除通行关系，「清空全部道路」同时清空路径与城市接边，不会自动重建。
- 河流是独立的路径图层，不会涂改底层地形。可选中、命名、新绘、重画、拖动控制点，或删除所选控制点、单条河流、全部河流；允许河口延伸到海面。新绘时可点击落点或按住拖动描线，至少两个点后完成保存。
- 删除所选道路或河流是一键操作，可撤销；地图获得焦点后 Delete / Backspace 也可删除所选路径。批量清空仍需要五秒内再次点击确认。河流草稿与道路草稿互斥，未完成路径会阻止应用、导出和据点移动。
- Ctrl/⌘ Z 撤销，Ctrl/⌘ Shift Z 或 Ctrl Y 重做；文本框中保留原生文本撤销。空格加左键或中键拖动地图，Ctrl 滚轮以光标位置缩放。适配同时考虑可视区域宽度和高度。
- 整层填充、还原图层、删除据点、清空全部道路或河流需要在五秒内再次点击确认，并且都可撤销。

## 保存与数据约定

编辑内容先保存在编辑器里，应用后才写入当前战局或所选剧本。进行中的道路、河流和未保存的据点表单会阻止应用与导出，避免产生看似成功但缺少最后一步的结果。

开始界面的「保存剧本」把当前地图保存到浏览器的独立 IndexedDB 数据库，按剧本隔离；刷新页面、切换剧本或新开局时自动使用。右栏可「载入已保存地图」或「恢复原始地图」；替换未保存编辑和恢复原始版本需要再次点击确认。恢复原始会移除已保存版本，仍可撤销并重新保存。写入或删除失败时不会先替换当前地图；原始项目文件不被覆盖，跨浏览器、设备或访问地址请导出补丁备份。原始剧本发生变化时不自动套用旧地图，需在编辑器中手动载入并核对。

进入战局后的「应用并保存」只修改当前战局的存档，不覆盖开始界面的剧本地图。已有战局继续使用自己的地图；旧存档没有编辑扩展时使用原始剧本，不受后来保存的自定义剧本地图影响。同页切换存档时，地图网格、道路、河流及地标均重新读取，不残留上一局的显示缓存。

每个剧本、地图及存档槽位有独立草稿。草稿使用 IndexedDB，不与 localStorage 中的大型战局副本竞争容量；兼容读取旧的 localStorage 草稿。草稿会恢复尚未应用的图层、城市资料、道路与河流绘制；未完成路径恢复后自动进入对应工具。如果源地图已经变化，则显示恢复 / 放弃旧草稿入口。

战局存档新增可选的 `world.mapEditor` 扩展，不改变旧存档版本。它记录编辑后的地图与行政资料，并保留城市改名、移动和删除。没有该扩展的旧存档仍按原有的历史数据迁移方式加载，防止旧地图坐标覆盖新剧本。

地图补丁与完整剧本均包含地形、州郡、道路、县治和行政资料。导入先在独立副本中解析并校验，再一次性写入；格式错误、尺寸不符、坏路径等失败不会改变当前编辑或消耗撤销。明确的空道路、水道、地标列表表示清空，不能悄悄重新生成默认数据。补丁仍固定为当前地图尺寸。

地图补丁文件不是可直接安装的模组压缩包；完整模组打包仍需独立的 manifest 和补丁文件。

## 验证

```sh
node tools/test-map-editor.mjs
node tools/test-map-editor-layers-lines.mjs
node tools/test-map-waterways.mjs
node tools/test-map-editor-elements.mjs
node tools/test-map-editor-select.mjs
node tools/test-map-editor-persistence.mjs
node tools/test-scenario-map-store.mjs
node tools/test-save-recovery.mjs
node tools/test-map-input.mjs
node tools/validate-data.mjs
```

真实浏览器检查使用独立 Safari 窗口与验证端口，避免重载正在游玩的窗口；需要 Safari 允许来自 Apple Events 的页面脚本访问：

```sh
node tools/start-game.mjs --no-open --port 8091
node tools/qa-map-editor.mjs
```

浏览器检查涵盖整笔绘制、撤销重做、失败导入、据点选择与显式移动、未保存表单拦截、独立州郡图层与自动归属、道路和河流节点拖动、单条删除、道路通行同步、未完成河流草稿刷新恢复、适配尺寸、提示栏固定、左右栏底边和窄窗口布局。截图写入 `/private/tmp/sanguo-editor-wide.png`、`/private/tmp/sanguo-editor-narrow.png`、`/private/tmp/sanguo-editor-province.png` 与 `/private/tmp/sanguo-editor-river.png`。

完整保存业务流另运行 `node tools/qa-map-save-flow.mjs`。它自动创建独立静态副本、随机端口和 Safari 窗口，验证保存、刷新、新开局、同页换档、空河流与地标、保存/删除失败保护及恢复原始；不会请求本地存档 API。截图写入 `/private/tmp/sanguo-editor-save-flow.png`，结束后仅清理该验证源的数据。

## 下一步开发建议

| 优先级 | 开发点 | 解决的问题 |
| --- | --- | --- |
| 高 | 道路交汇节点与路段图 | 当前连通关系仍以城市端点为单位；两条线在格子里交叉不等于建立可通行的交汇口。需要显式路口、接路与拆分路段，并让行军与补给共同读取。 |
| 高 | 县治及州—郡—县层级编辑 | 城市州郡归属已由边界网格自动计算；下一步补齐独立县治搬迁、郡治/州治指定、县域财政管辖和郡属州的完整历史行政资料。 |
| 高 | 历史底图参考层 | 支持图片叠加、透明度、控制点配准、锁定和网格坐标，方便用户校对史籍地图与手绘道路。 |
| 中 | 框选 / 多边形 / 批量属性编辑 | 精确划出大块疆域、批量归属与改名，减少宽笔刷和连片填充之外的重复操作。 |
| 中 | 可定位的校验结果 | 点击问题直接定位对应据点、道路或格子；进一步检查孤立区域、郡跨州、路口不通和行政资料差异。 |
| 中 | 多版本草稿与模组打包 | 草稿命名、版本对比、恢复历史，以及包含 manifest 的可安装压缩包。 |
| 中 | 完整县域名录与人口模型校准 | 105郡国的人口来源与名称别名已统一；下一步扩展当前253个战略县治的名录，校准城邑份额和县级分配权重，不把估算当成逐县史籍口数。 |
| 低 | 触屏双指缩放、图层缓存与空间索引 | 当前地图使用帧合并绘制；地图扩大或节点增多后，再按实测瓶颈增加局部缓存和裁切。 |
