# 收成、开局储粮、中央济粮与军队屯田

2026-10-17。此轮落实首年初始化、开局储备校验、只读预报、中央自动济粮，以及军团屯田按钮；承接驻屯官粮减耗。

## 收成口径

- 首轮仍为统一九月月末年度收获，三月至九月作为游戏抽象生长期，并非各地农作物准确农历。地区作物历、复种与独立耕地系统留待后续。
- 年度规模沿用原财政产粮公式。每日生长期累计，九月月末才转为可征粮；征收耗损、地方留用、上缴与运输继续走原账本。
- 该数值是人口税基等因素推算的可征粮，不是全部农户总产量；没有将民食、留种与官粮合算成可用库存。
- 新局按开始月份补足已经形成的田间进度。冬季不累计普通作物，秋收后开局不会补一整季未收粮。收获日与屯田累计有日期去重。
- 普通农业仍复用现有每日财政循环；按日积分，不新增逐田块扫描。屯田只扫描现有军团，不创建农田格或人口 POP。

## 开局库存

- 县仓目标按当地普通守军、官僚及驻城军团的实际日常官粮支出，覆盖至下次收获并加六十日储备；不超过仓容，不削减原有较高库存。
- 明显低库存剧本（原库存比例折算系数低于 0.8）保留缺粮设定。普通局县仓不足的储备缺口由中央开局资源兜底；这不保证飞地可达，预报仍显示县仓风险。
- 只在新局初始化执行。读档保留当前中央、地方、军仓和田间累计，不按新局标准补发；新增存档字段为可选，不改变 v18 的既有一次性迁移。

## 中央济粮

- 默认开启，府库的「收成与中央济粮」可暂停或开启。每五日检查，优先处理余粮可用天数最少的县仓，每势力每次最多八批，每批最多二万石。
- 县仓与已在途的可交付粮不足三十日时安排济运，目标九十日，受县仓容量与中央可支配库存限制。中央保留首都三十日需求及手工中央供粮线指定的底粮。
- 拨出时扣中央府库，途中计损耗、延误、阻断或没收，抵达后进入县仓。同城中央转县仓也按下一次运输结算入库。
- 已在途或受阻的同势力县仓粮计入缺口，避免不断重复发运；受阻粮不计入「收获前可按时使用」的预报。
- 被围、失守或没有安全官路／水路的地方不能瞬移接收。指定前线仓优先由玩家配置的粮线供给，通用济粮不叠加抢占其目标。
- 删除旧的中央直接补入军仓的瞬移兜底；本郡与就近地方调粮保留原规则。中央统筹、郡县自给不再跨郡即时抽粮，由中央济运接续。
- 当前固定三十日发运阈值对超长运输仍可能不足，需要预先设置后方到前线仓的专用粮线；按实际运输时长自适应阈值是后续改进。

## 军队屯田

- 军团详情「开始屯田／停止屯田」加入每日军令队列，军事命令簿也可进入军团详情设置。只接受本方军团，不因操作详情而直接产粮。
- 仅安全驻己方城、没有行军／野外位置／围城／败退／袭扰任务的军团可屯田。离开原驻地或被围后停止收益，已有田间成果留在当地。
- 默认最多投入一半健卒，同县总投入不超过当地人口的 10%（现阶段土地承载的代理指标）。多个军团共享此上限，按稳定 ID 分配，不能分拆军团无限增收。
- 满额投入时在驻屯日粮基础上再减少一半官粮净支出；投入不足按比例减免。同样比例降低训练速度。健卒、伤员、战俘计粮口径不变，出征备粮一律按完整野战日粮。
- 每名实际参与者按全年三石的可征粮增量逐日积累，直到下一次收获才进入可征粮并清零。系数是游戏平衡数值，不声称史载亩产；冬季投入抽象包含整地、维护与就地供养，尚非逐作物农活模拟。
- 城市预报显示屯田劳力、已积累增收；军团军粮页显示「屯田供养」及出征日粮。未收成部分不能供军。

## 粮食舆图与运输（2026-10-17）

粮食图层悬停县治显示现粮、实际日耗、按当前库存可维持天数、下次秋收日期与剩余天数、预计可征及净入仓粮、在途和收获前缺口。屯田县另示投入兵员与累计收成；本方显示中央济粮状态。郡汇总仅合计同势力县仓，不代表各县可以即时互通。敌方按县级情报精度隐藏或估算；郡中尚有未探明县时不显示全郡精确库存。预报不消耗随机数，也不修改账本。

粮食和补给图层同时显示上缴中央、中央济粮、地方调粮、军队粮道、配置供粮线和运输受阻，支持图例开关。实际粮车与虚线供粮计划分开；沿真实官路／水路绘制和命中提示，不用起终点直线代替道路。配置线路断路时不绘制虚假的可通行连接。财政粮车提示装载、预计交付、损耗、当前位置与到达日程；军队粮队提示现粮、护运及余程，新粮队记录装载量以计算已损失，旧存档缺装载记录时不推算原始货量。粮队及供粮线在府库有「舆图查看」入口。
