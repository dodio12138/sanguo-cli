# 战斗系统审计（2026-10-18）

范围：主力野战与持续战局、道路追截、小队突击／阻击／袭扰、出城迎战、突围、伤员与溃散归建、俘虏分配、改编及驻军归还。围城专项另见 [围城逐日结算与破城去向](SIEGE_DAILY_AND_CAPTURE.md)。以下区分已修错误与尚需设计的玩法。

## 已修复的确定性错误

| 问题 | 原因与修复 |
| --- | --- |
| 一名伤员归建产生负兵种 | 原来逐兵种四舍五入，而且边分配边改同一份权重；两兵种各占一半、一人归建时，最后一个零兵种可能变成负一。改为固定权重、累计整数配额，分配总量严格等于归建数。 |
| 多支胜军分配俘虏时多出或丢失人数 | 逐军独立四舍五入使一俘虏分给三军可能无人收到，或多俘虏被复制。与归建共用整数配额分配，按实际俘获总量守恒。 |
| 受围伤员享受安全城内医疗 | 医疗休整条件没有排除被围城，现按野外条件；断粮依据当天实际口粮缺口，不能等补给指标降到零才识别。治疗与病死的合计也不超过伤员池。 |
| 远方或敌占县被当作一步退路 | 原首选退路只排除敌军驻扎，没有检查相邻及归属；现只接受真实相邻己方／友方节点，或出城迎战可退回的本城。 |
| 道路交战主动后撤跳回节点 | 自动败退保留道路接触点，但手动撤退没有传入该位置；现从战局读取道路位置，保持坐标连续。 |
| 未宣战对峙可刷战法蓄势 | 原先先积累或消耗战法，再检查宣战。调整为外交检查通过后才处理真正参战军团的战法，支援军同样参与。 |
| 未知战俘处置等同释放 | 原未知枚举落入默认释放分支；现先验证动作，再修改战俘池。 |
| 改编可构造负数或不存在的兵种 | 仅校验总数相等，负步兵加超额骑兵也会通过；现校验已知兵种、非负整数与总数。 |
| 野战详情显示早期战报，且不随日期刷新 | 原日志按时间正序却取第一个事件。现选最新的有效战况，倒序展示历史，打开窗口随每日结果刷新；编辑输入时不抢改控件。 |
| 归还驻军被整百步长卡住 | 输入步长改为一人，增加「全部可归还」按钮；规则层接受整数尾数并严格验证范围。原至少保留一百人规则不变。归还后补员目标设为剩余兵力，避免下旬自动抽回刚归还的兵。 |

同类兵员输入中的整百限制也从部将兵数、自动补员目标、守军征募目标、分遣和突围人数中移除。各功能的最低人数限制仍有效；突围规则增加整数人数校验。

## 本轮续修已实现

出城迎战已接入多日战局，突围成功后沿道路行军并携带武将／天子，持续日战解除八日硬上限；攻城筹备增加军士人日及实际材料经费，缺资停工。实现、存档与回归细节见 [战斗系统续修](COMBAT_CONTINUATION.md)。材料采用现有钱币折价，未新增木石资源或自动征发民户。

第二轮覆盖战斗全部关联专项及边界补测，新增错误与修复见 [全面回归记录](COMBAT_REGRESSION_2026_10_18.md)。

## 仍需继续设计的项目

1. **普通驻军的兵种、伤员、老兵**：当前普通驻军仍为单一人数。迎战伤员已留在城守营调养，但整军归还／销编后的兵种和老兵仍需完整地方模型。
2. **道路战场标记**：军团与败退位置沿真实道路，但部分野战详情仍以据点锚定；可让战场图标、战报定位也使用实际道路接触点。
