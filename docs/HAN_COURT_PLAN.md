# 汉庭系统企划

> 状态：企划已定稿（2026-10-14，第 9 节为用户拍板的决定），待按第 8 节分期实现。战斗、围城突围与补给的配套改造见 `docs/WARFARE_LOGISTICS_PLAN.md`。

## 1. 要表达的体验

汉末诸侯打的是两张地图：一张是兵马实际占住的地盘，一张是朝廷名分认可的秩序。献帝本身没有兵，但「谁握着天子」「谁肯奉诏」会实打实改变战局：

- 董卓、李傕挟天子，关东诸侯名义上仍是汉臣，却不奉他们的诏。
- 曹操迎天子都许，以诏书封官、安抚关中，官渡前夕钟繇镇关中，马腾、韩遂送子入侍，曹操得以全力对付袁绍。
- 袁术称帝，名分尽失，四面讨逆。
- 刘备、孙权一面受汉官，一面自行其是；219 年刘备自立汉中王，名分与实力再次分离。

本系统用一个桌面程序窗口「汉庭」承载这些，并新增两张舆图：**名义控制区**与**实际控制区**。

## 2. 核心对象

### 2.1 朝廷（全局唯一，存于 `state.court`）

| 字段 | 说明 |
|---|---|
| `emperor` | 当今天子：姓名、年号、状态（在朝 / 被劫 / 流离 / 禅让后废）。190 年起为献帝刘协 |
| `capital` | 都城据点 id：洛阳 → 长安（190）→ 洛阳（196）→ 许（196 起）；可随剧情或「迁都」诏改变 |
| `controller` | 挟天子者（势力 id），可为空（天子流离时） |
| `authority` 天子威望 0–100 | 朝廷名分本身的分量：天下越乱越低，平乱、祭祀、四方朝贡则升 |
| `control` 控制力 0–100 | 挟天子者对朝廷的把握：都城驻军、在朝时长、朝臣归心使之升，战败、谋诛、天子出奔使之降 |
| `offices` | 汉官名录：官职 → 现任者（人物 id、所属势力、授予日期、授予者） |
| `edicts` | 进行中的诏令（免战、讨逆、征召等）及到期日 |

### 2.2 各势力对汉庭的态度（`state.court.stances[forceId]`）

| 数值 | 范围 | 含义与来源 |
|---|---|---|
| **忠汉** | 0–100 | 势力本身的立场，变化慢：刘备、刘虞、孔融高；袁术、董卓低。受君主性格、汉室宗亲、历史事件影响 |
| **服从** | 0–100 | 对「当前这个朝廷」的实际听命程度，每月重算：忠汉 × 天子威望为底，加上与挟天子者的关系、实力差距（挟天子者越强越服）、距离都城远近，减去近期抗诏 |
| **名分** | 累计值 | 本势力人物所受汉官、爵位之和；高名分利于招揽名士、安定民心、AI 外交，并作为「州牧」辖区的正当依据 |

挟天子者自身的服从恒为 100；称帝者的忠汉、服从归零。

### 2.3 官职与爵位（两套分开，均可任命）

**官职**是职事，有名额、有职权、可罢免，记在人物的 `hanOffice`：

| 层级 | 官职（举例） | 职权与作用 |
|---|---|---|
| 公 | 太尉、司徒、司空、丞相（208 后） | 朝堂首脑；在朝者提升控制力，外藩受此职名分大增 |
| 将军 | 大将军、骠骑、车骑、卫将军；前后左右将军；征、镇、安、平四方将军；杂号将军（讨逆、讨虏、破虏等） | 军事名分；「奉诏讨伐」的依据；统军者士气小幅加成 |
| 州 | 州牧、刺史 | 认可对该州诸郡的统辖；名义图为该州描金边；同州可有「朝廷所授」与「自领」之争 |
| 郡 | 太守、国相 | 朝廷任免的最低一级（见第 9 节第 3 条） |
| 中层 | 校尉、中郎将、都尉 | 笼络次要人物 |

**爵位**是身份，世袭（袭爵）、无职权、不占名额，记在人物的 `hanTitle`：

| 等级 | 爵位 | 作用 |
|---|---|---|
| 王 | 诸侯王（汉中王、魏王等，219 前后特例） | 极高名分；非刘氏称王要付出忠汉代价 |
| 公 | 魏公等 | 九锡线的一环 |
| 列侯 | 县侯、乡侯、亭侯 | 人物忠诚上升、势力名分上升；君主死后由继承人袭爵 |
| 关内侯 | 关内侯 | 赏功用，低成本笼络 |

两套都可由挟天子者授予：官职受名额与职位空缺限制，授出等于让渡一份职权；爵位不限名额，但滥封会稀释天子威望。自立者在本国内封官封爵只算「自领」，名分折半。

表格数据放在 `game/data/common/han_court.json`：官职写秩次（万石 / 中二千石 / 二千石……）、名额、职权与可授对象，爵位写等级、食邑与袭爵规则。

## 3. 两张新舆图

在现有「关系 / 粮食 / 武将」分析图层之后加两个按钮，复用 `MapView.DYNAMIC_LAYERS` 的按日缓存：

- **名义**（汉庭名义控制区）：按郡着色
  - 奉汉：势力未称帝、未与朝廷断绝，统一用汉室赤色，按名分深浅
  - 自立 / 称帝：单独标色（袁术称帝后的淮南）
  - 化外：无主、山越、外族
  - 州牧受封的州描金边，可以一眼看出「朝廷认的是谁」
  - 与所在郡归属不同的独立县（如郡中一县据守不降）单独描边
- **实控**（汉庭实际控制区）：按郡着色
  - 天子直辖：挟天子者本势力
  - 奉诏：服从 ≥ 70
  - 观望：服从 40–70
  - 不奉诏：服从 < 40
  - 逆贼：被朝廷宣布讨伐或称帝
  - 都城以玺印符号标出

鼠标悬停显示该郡所属势力的忠汉、服从，以及该地汉官（州牧 / 太守）是谁、由谁所授。

## 4. 「汉庭」程序窗口

桌面应用（与府库收支、军政档案同级，可最小化到任务栏），分四页：

1. **朝局**
   - 天子、年号、都城、挟天子者
   - 天子威望、控制力两条刻度
   - 三公九卿与在朝重臣
   - 近期诏令与朝局大事
2. **官职**
   - 汉官名录：按公、将军、州、郡、爵分组，显示空缺与现任者
   - 本势力人物所受汉官
3. **诸侯**
   - 各势力的忠汉、服从、名分、所受最高官职，可排序
   - 一行一个势力，点击可直接对该势力发诏或上表
4. **诏令 / 上表**
   - 按本势力身份列出可用操作、代价与成功率预估（见下节）

窗口顶部给一句身份说明，例如：「你挟天子以令诸侯」「你奉汉为名、实行自主」「你已自立，朝廷视为逆贼」。

## 5. 交互：按身份分

### 5.1 挟天子者

| 操作 | 效果 | 代价 / 风险 |
|---|---|---|
| **册封** | 授他势力人物汉官或爵位：对方关系、服从上升，名分归对方；可作为安抚手段 | 消耗天子威望与控制力少许；封得太高会让被封者坐大（名分可用于争夺州牧） |
| **安抚诏（免战）** | 对某势力下诏和解：对方接受则与挟天子者订立定期互不侵犯（复用现有 `non_aggression` 条约），AI 在期限内不对挟天子者开战 | 需对方服从达到门槛；常配合册封、送质子；对方抗诏则服从下降、本方威望受损 |
| **任免州郡长官** | 实控区内：直接任命太守、刺史（提升治理加成，人物得名分）。奉诏势力的郡：发出改任要求，对方按服从判定接受或抗命 | 强力诸侯（实力远超、服从低）可不受；抗命记入其「抗诏」，降低其服从、给朝廷讨逆口实 |
| **奉诏讨逆** | 宣布某势力为逆贼：对方失去名义区；其他势力对其关系下降、AI 更愿参战；本方出兵获得士气与民心加成 | 威望消耗大；讨伐失败则威望、控制力下滑 |
| **联军攻势** | 以天子名义号召讨伐某势力：指定集结地、集结期限与共同进攻目标、发动日期；受诏势力按服从与关系决定是否出兵，到期在集结地会师后同时进攻（在现有 `coalitions` 上补集结地与时间表） | 威望消耗随参战势力数增加；无人响应则威望受损；联军按期失约者服从下降 |
| **征召入朝** | 征召他势力人物入朝为官（如马腾入朝为卫尉）：对方接受则其人离开原势力、对方服从大增 | 对方可拒；征召本方质子可提升控制力 |
| **迁都** | 把都城迁到本势力据点（如迁许）：控制力大增 | 迁都途中天子有被劫风险；旧都所在郡民心下降 |
| **加官进爵（九锡线）** | 自封丞相、魏公、魏王：控制力与本势力名分大增 | 天下忠汉降低，朝中忠汉人物（荀彧型）可能离心；走到底可触发「禅让」终局 |

### 5.2 其他势力

| 操作 | 效果 |
|---|---|
| **上表 / 朝贡** | 向都城献金粮：提升名分与对朝廷的关系，可附「请封」请求某官职，由挟天子者（AI 或玩家）批复 |
| **奉迎天子** | 天子流离或控制力很低时，兵临都城或护驾即可夺取挟天子者身份（196 迎献帝的机会） |
| **勤王 / 衣带诏** | 忠汉高、挟天子者控制力低时，可与朝中忠臣密谋：成功则天子出奔、控制力骤降；失败则主谋被诛、本方名分受损 |
| **抗诏** | 拒绝改任、征召或安抚：保住实际利益，但服从、名分下降，给朝廷讨逆口实 |
| **自立 / 称帝** | 允许。脱离汉庭：名义区改为自立色；天下各势力对其忠汉相关的关系恶化，本势力忠汉人物离心；汉庭可据此发「讨逆诏」或「联军攻势」征讨。称王（汉中王型）代价轻于称帝 |

### 5.3 官渡前夕的例子（200 年剧本）

- **开局**：曹操挟天子都许，控制力约 70；马腾、韩遂忠汉中等，服从约 55，处于观望。
- **曹操稳住关中**：玩家曹操在「诸侯」页选中马腾，册封马腾为征南将军，并下安抚诏。马腾接受，与曹操订立一年免战，还可以选择送马休、马铁入质，进一步提升控制力。
- **效果**：关中这一侧在免战期内不会开战，曹操能把兵力集中到官渡。
- **袁绍一方**：可以上表请封抬高名分，或走衣带诏、联络刘备勤王一路，去削曹操的控制力。

## 6. 与现有系统的衔接

| 现有系统 | 衔接方式 |
|---|---|
| 世界外交（同盟、互不侵犯、宗藩、宣战） | 免战诏产生带期限的互不侵犯；讨逆触发各方关系下降；`worldVassals` 可承载「受封藩属」 |
| AI 出兵门槛（`campaignDecision`） | 读取免战诏与讨逆状态；挟天子者 AI 在大战前自动对次要方向发安抚诏（官渡式稳侧翼） |
| 事件系统（`runWorldEvents` / `applyWorldActions`） | 新增 `court` 类动作：迁都、换挟天子者、授官、称帝、禅让；把迁都长安、天子东归、迎天子都许、袁术称帝、衣带诏、魏公魏王、汉中王等史事改写为朝局事件 |
| 势力内部官职 | 汉官另记，不占内部官职名额；受汉官的人物忠诚略升 |
| 人物继承 | 君主所受汉官不自动传给继承人，可由朝廷「袭爵」 |
| 消息分级 | 诏令下达、抗诏、天子易主、称帝列为重要或紧急 |
| 舆图图层 | 新增 `court-nominal`、`court-actual` 两层，按日缓存；他方服从等数值受情报等级遮蔽 |
| 存档 | `state.court` 随存档；旧存档载入时按剧本初值补建 |

## 9. 已定的决定（2026-10-14）

1. **天子归属看战况**：攻破都城不自动得天子。城破前守方可「突围」，带天子与守将以小股部队冲出，按包围完整度、兵种与将领判定成败；失败则天子落入攻方之手。突围与城破处置在《战斗与补给改造》中实现（W3）。
2. **允许九锡、受禅、自行称帝**，但会引来忠汉相关的关系恶化；汉庭可对其发「讨逆诏」，也可发动「联军攻势」：选定集结地、共同攻击目标与发动时间。外交系统其余优化另议。
3. **任免只到郡太守**。县一级不由玩家直接任命，为之后的「世家系统」留口：县吏由当地世家选拔或把持，玩家要处理与世家豪族的关系，关系好坏影响政府效率。城市页面将州治、郡治、县治分开展示，各自对应州牧／刺史、太守、县令（世家）。
4. **两张地图都按郡着色**；与郡归属不同的独立县单独描边；州牧所辖州描金边。
5. **抗诏同时看服从与实力**：实力悬殊时，服从中等的强诸侯也可能不受诏。
6. **官职与爵位分为两套**，均可任命（见 2.3）。

## 10. 与战斗、补给改造的先后

汉庭的「天子突围」「联军攻势」依赖新的战斗与围城模型；P0、P1（数据、窗口、两张舆图）与战斗改造互不依赖，可先行。建议总顺序见 `docs/WARFARE_LOGISTICS_PLAN.md` 第 8 节。
