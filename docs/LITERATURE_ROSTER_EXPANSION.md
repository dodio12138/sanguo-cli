# 史籍人物补遗与六剧本配置（第二轮，2026-10-15）

本轮新增 **451 名独立人物**（史书 440，演义 11），新建 **32 家世家/家族档案**，补齐 **27 家既有世家**的成员与亲缘。加上上一轮 99 人，两轮累计新增 566 人；当前官渡名册共 1301 人，包含在任、在野及未登场人物。

1000–3700 的区间只是检索规模参考，本轮未据此宣称全书穷尽。名录只用于查漏；正文、裴注、后汉书、晋书和演义分开注明，姓名、父系与剧本配置以对应原文核对。晚期子孙收入共享人物库，不能提前在汉末当官；早夭与无法确认独立身份者不计入可用新人物。

原文见证 **458 条**（其中 7 名已见于原有剧本专有库，不重复新建），分属 73 卷/回。见证存于 「game/data/reference/literature-roster-evidence.json」，含来源、正文/裴注标记、对应简称、摘录及原始 wikitext SHA-256。底稿 「tools/roster-literature-data.mjs」、「tools/roster-literature-clans.mjs」、「tools/roster-literature-government.mjs」；生成器普通执行与检查均无需联网。

- `node tools/expand-officer-postings.mjs --check`：名册、家族、官制及本记录幂等同步。
- `node tools/test-literature-roster.mjs`：六剧本真实加载、原文见证、在任驻地、亲属父系、同名分族、幼年及旧局往返。

- `node tools/run-tests.mjs --quick` 及相关长测：复核官制、家族、人口和存档体积；实际结果记入开发进展。
- 地图源文件、陆海、州郡、道路、河流与城池坐标及归属未修改。新旧指纹差异只涉及开局官员字段；兼容表仅接纳已审校的具体旧版基线。
