# 战斗功能全面回归与边界补测（2026-10-18）

接续 [战斗续修](COMBAT_CONTINUATION.md)。目标是检查现有战斗及关联功能的错误，不修改地图、历史剧本资料或用户存档；本轮源码尚未提交或发布。

## 覆盖范围与证据口径

- 主力野战：即时与持续结算、增援、战法、阵型、接战宽度、组织瓦解、撤退、停战、交战状态与保存恢复。
- 围城：围困／强攻／水攻／地道、总攻、劝降、突击、迎战、突围、城内断粮、工事与经费、破城驻防、守军去向、武将与天子。
- 小队：逐格路径、分遣、突击／阻击／袭扰、期限、迟滞、独立归队、自动与手动合队、失守后的归路。
- 行军与后勤：真实位置、追击／迎面截击、撤退折返、军仓与城仓、粮队启运／追送／截获／撤销、仓库、屯田和年度收成。
- 军事管理：军职、编军、改编、补员、训练、解散、归还驻军、伤员、老兵、溃散、战俘；并检查行政、方面、AI、朝廷、剧本事件和存档对战斗状态的影响。

原有 34 组战斗与关联专项全部通过，但新增边界断言先在原实现中复现了失败，再据此修复。测试通过只能证明已覆盖案例，不等于穷尽所有玩家操作组合。此次新增规则没有改动窗口布局；此前浏览器的迎战、收兵及工事验收记录保留在续修文档，此外，本轮在独立静态服务和浏览器中验证守城列表只显示实际驻军，再真实点击「出城迎战」、推进一日，确认窗口转为持续野战并展示实际双方部队；截图已检查。

## 新发现与修复

| 问题 | 修复与新增验证 |
| --- | --- |
| 没有步兵的骑射混编分遣 101 人会生成负步兵 | 分遣共用累计整数配额；每个兵种拆分前后分别守恒，人数非负。 |
| 野外合队可突破小队人数上限 | 野外目标军合并后仍须满足小股部队上限；返回驻城主军的正常合队不受此限制。 |
| 护驾军并编后天子关联旧编号而流离 | 护驾关联转到新主军；普通合队也清除目标营不适用的临时守军归城标记。 |
| 同日删军、再编军／分遣可能复用编号 | 使用随战局保存的单调编号，避开现存军团、粮队及转运引用；迎战、突围、破城撤军也统一生成编号。 |
| 小队撤回的目标失守后永远停在原格 | 到达后重新寻找安全据点；无可达安全地点时明确转为就地收拢。 |
| 行军军团可按后方锚点解散，伤员／军资／战俘丢失 | 解散须安全驻扎；伤员或溃散待归者留原营调养。健康兵、钱粮布帛、战俘实际移交地方，粮队另按台账处理。 |
| 编军没有改编同等的整数和兵种校验 | 拒绝负数、非整数、未知兵种，失败不改变守军或军团。 |
| 持续交战军团仍被行政流程训练、抽补；远方小队锚点阻挡补员 | 接战军团不参加驻城训练和自动抽补；野外敌军不因后方锚点形成虚假驻城封锁。 |
| 已离城和已溃退军团仍算守城／被破城吞掉 | 防守军口径统一排除已在路上、野外、溃退和其他接战军团，破城入口再校验；这些军团的随军人物同样不因旧驻地失守被俘。 |
| 道路追截误加入同一据点的另一场持续战斗 | 加入城下战局需匹配双方势力，且当前不是道路接战；道路战保存独立接触位置。 |
| 野战围歼后败军军资、原押解俘虏消失，俘获取整不守恒 | 军资交给胜军，本方被俘者获释归建、其他俘虏移交；健卒与溃散俘获分别取整。老兵成长增加非负下限。 |
| 粮队启运尚未推进、或刚读档便撤军时失账 | 启运即登记，台账随存档保存，旧档从实际粮队恢复；撤军后粮、护送只结清一次，截获不保留可误返还的旧账。v18以前旧粮食口径的在途粮和台账同倍率迁移，重复迁移不再放大。 |
| 失效粮队节点可能在野外距离计算中崩溃，追送失败向敌占来源退款 | 推进前校验节点和索引，失效路线有返还／失散结果；折返只能归还仍属本方的来源库。 |
| 行军部队按旧驻地隔空收粮 | 粮队追送到当前接应节点，实际会合后交粮；等待会合期间粮食仍在粮队中。截粮收益上限也不超过实存粮。 |
| 路上切换袭扰、扎营、伏击或改道会清空进度，主动折返跳回起点 | 驻地动作须抵达据点后执行；改变当前路段的改道需等该段完成，撤退折返则保留实际位置并沿路返回。专门的道路中途驻营模型未新增。 |
| 明确给敌军或已失效编号下调动命令仍可操纵敌军／默默改派本军 | 调动与驻地动作只接受指定本方军，明确的非法编号不触发默认军团回退；失败保持双方原状。 |

## 最终结果

- 全仓库既有测试 **135/135 通过**，包含长测，三进程共 626 秒。此次全量运行启动后新增的战斗矩阵单独执行通过，测试文件现为 136 个。
- 六个剧本（190、194、200、208、211、219）各 730 日长局通过；全量还包含其余剧本启动、后期剧本、黄巾、全部命令、方面、财政、运输、存档及界面关联验证。
- 最后修改后对受影响项追加复验：战斗审计、战斗矩阵、主动折返与追击、军职、分遣／合队、围城及突围、粮队、旧档迁移、战况窗口和一年存档均通过。新用例未靠放宽旧断言或存档限额通过。
- 缓存版本检查、JavaScript语法检查、`git diff --check` 通过；本轮独立浏览器与静态服务已关闭，用户地图和已有存档未改动，尚未提交或发布。

普通驻军完整兵种／老兵模型、道路战场图标的精确位置仍是既有后续设计项；不将这些未实现项目称为已修复。此结果覆盖测试列出的状态与操作，不能当作所有可能组合均无错误的证明。
