# 城市饥荒、流民与迁徙（2026-10-18）

## 现状与改动

旧机制已有按月死亡、战乱逃户、流民迁徙与安置，但仅看人口结算当日的空仓；同时被围直接认定严重缺粮，即使城中仍有粮。改为每日记录城市压力，人口本体继续按原月度分日结算，不额外逐日扫描所有 POP 或另扣一份饥荒死亡。

- 普通城市空仓前7日缓冲。缺粮记忆在连续空仓60日时达到严重饥荒，增加原有月死亡、降低出生与健康、农户逃散为流民。最高记90日；恢复有粮后每日消退2日压力，避免断粮／到货瞬间来回切换。
- 关口／渡口不记录这项居民饥荒压力，军队缺粮继续由军粮、围城规则处理。县记录取其实际县治粮仓节点，无县治才回落到所属节点；没有另造一套人口。
- 实际当地交战、有效围困、占领每天累计战争压力，20日达到完整强度，最高60日；和平后每日消退0.25日压力。最近30日战事仍保留轻度不安；有粮也可能因战争产生流民。
- 粮食充足且战争压力基本消退，流民按既有比例逐月安置；否则往相邻较好地方迁移。目的地需比来源评分高0.15且超过安全底线，并考虑粮食、治安、战乱与流民拥挤。关津和被围城市不作为目的地，被围来源不允许瞬移穿越封锁。
- 迁徙从来源 POP 扣减后加入目的地 POP，途中损失仍记原 `popStats.lost`，出生和死亡分别记原统计。攻城原有直接伤亡仍保留，本次没有增加一笔逐日饥荒死亡。

粮仓仍是官粮账本，并非另行模拟所有百姓私粮；七日缓冲和持续压力是当前版本对民间抗冲击能力的简化。严重围城的既有直接伤亡与本次月度人口衰减是不同来源，均参与人口守恒账。

## 性能与存档

每天对城市与围城部队做轻量压力记录，不每日计算各职业、年龄和迁徙。人口仍每处每月一次、分28组处理，世家与家族频率不变。日期戳防止同日压力重复累计。压力为城市动态字段，自动随现有存档保存；旧档缺字段从零累计，不改旧人口、不重发粮。

在存档往返测试发现：同数量的城市数组被读档替换时，`popPlace` 原索引只比条数，会继续返回旧对象。现同时校验城市／县数组引用，避免迁徙作用于脱离当前战局的旧节点。

## 验证

`tools/test-population-stress.mjs` 使用官渡人口逾十万的大城市副本，验证七日缓冲、两月持续断粮后的缓慢死亡、战乱流民、迁往有粮邻城、供粮和和平恢复、关津隔离、围城封锁、人口收支、日去重、只读无副作用和存档往返。旧人口测试保留全年收支守恒和730日推演。

本次没有访问用户游玩存档，也没有修改陆海、区划或道路。最终验证：人口／人口口径／县级模拟／日历／围城／存档体积相关7/7通过，其中包含730日人口推演。快测96项通过，剩余1项为并行测试期间资源哈希尚未同步；同步后单独复测 `test-asset-versions.mjs` 通过，97项均已验证通过。粮食专项10/10、数据校验与 `git diff --check` 通过。
