# 小队行动与军事图层

2026-10-17 军粮调整：安全驻己方城的军团采用「驻屯供养」，每日官仓净支出每口 0.033 石；行军、野外驻扎、攻守围城、败退或主动袭扰采用「行军战备」，每日每口 0.066 石。伤员全份、战俘半份不变。前者是就地供养的游戏抽象，并非士卒饮食减半，也不是完整屯田生产模拟；不另增发粮食。出征备粮始终按野战日粮计算，离城不缩水；存档库存不折算、不补发。

2026-10-16，接续 [战斗系统开发规划](BATTLE_SYSTEM_NEXT_PLAN.md)。本次实现小股部队逐格行动、局部接战和部队状态显示。

## 操作

1. 点击军事图层的部队标记或兵力条，打开军团详情。
2. 点击“分遣 / 小队行动”。大军默认分遣 1000 人；100—3000 人的部队可以将分遣人数设为 0，以整队执行。
3. 选择突击、阻击、袭扰、隐蔽休整或撤回据点。输入目标格，或点击“在军事地图选点”后在舆图上选择陆地；Esc 取消选点。
4. 确认后进入本日命令队列，日结算时执行。处于逐格行动中的部队从同一入口改令；普通城际调兵须在撤回据点后执行。

## 规则

| 行动 | 行为与代价 |
| --- | --- |
| 突击 | 在接近敌方野外部队或行军路段时进行一次局部接战，随后沿地形格撤回己方据点。 |
| 阻击 | 停留或前进途中接敌，降低敌军组织度和当日行军速度；自身也承受伤亡与组织损失。 |
| 袭扰 | 较低烈度接战并削弱敌方组织，在实际靠近粮队经过节点时复用既有截粮规则。 |
| 隐蔽休整 | 暂停主动接战，恢复组织；仍须吃随军军仓，也可能被敌方小队发现、攻击。 |
| 撤回据点 | 逐格返回最近可达的己方安全据点，抵达后才恢复驻城就食、补员、疗养和军职调整。 |

兵力上限默认 3000 人，每方至多保有 8 支由军团拆出的别部；一次目标距离上限 24 格，路线不超过 90 步。主力与小队并存，不把全部主力转为格子棋。正在城际行军的部队须先停下，围城军不能直接分兵，被围城内须走原有突围流程。

分遣按比例划分兵种、老兵、钱粮和布帛，健卒从原军真实扣除，伤员与俘虏留在原军。没有指定人物时由普通别部军吏带队，不复制原军主将。驻城开拔可从城仓领取携粮，这只是城仓到军仓的转移；野外再分兵不会从后方城池隔空补粮。

逐格路线复用当前地形的四向陆路寻路。山地、林地、泽地和渡河更慢，骑兵在可通行地形上较快；海格不可通行。没有官道也能到达并停在任意可达陆地格。部队不会因走到城池格就自动攻破或占领城池；本次局部接战对象是野外或在途部队，城池攻守继续使用原系统。

局部接战检查真实格位置与敌军本日扫过的陆路范围，不等待军队抵达下一个城镇。只有战争双方交战，水上行军不被陆上小队隔水攻击。每队有接敌冷却，同日不反复刷伤害，重新下令不清除冷却；每支目标同日至多承受一次这类局部接战。敌我悬殊、组织或士气过低时小队主动脱离。接战造成阵亡与伤员，伤员仍属于部队并继续耗粮；迟滞有上限，不使万人主力被小队永久锁死。

## 组织度与地图

新增可存档的部队组织状态 `cohesion`，旧军团默认 100。行军、急行军、逐格穿行及战斗使之下降，驻城或扎营休整恢复；缺粮继续恶化组织。既有携粮负担仍构成组织上限，实际组织度取部队组织与携粮组织上限的较低者，战力、溃散线、行军和详情沿用同一入口。

“军事”图层以势力着色，显示部队名、兵力条和组织度条；缩远时采用紧凑条，悬停查看完整说明，点击进入详情。同地部队标记错开，部队条避让并能点击。兵力条以该部队记录过的峰值作尺度；兵力数字表示当前健卒。己方和观察者显示精确值，他方按情报显示概数和组织档位，未探明者不显示。

新发生的小战场在军事图层显示“突 / 阻 / 袭”标记，点击查看接战经过并跳转参战部队或调整小队任务。普通图层继续使用原来的简洁军团标记。

## 状态、性能与兼容

- `fieldPosition` 是实际野外位置，`city` 仅保留后方归属锚点。财政、训练、补员、守城、伤员康复和战俘入营不能将该锚点当作实际驻城；幕府与 AI 也不能把野外小队重新抽为普通闲置军团。
- 每日处理行军、接战、组织与军粮；寻路只在下令或自动撤回时进行，平日消费已保存的逐格路线。地形缓存和路段索引共用；一次行动的搜索范围、路线长度和别部数量均有限制。
- AI 在接近交战敌军行军路线时按日概率选择阻击，通过与玩家相同的分兵及寻路验证，不免费生成部队。
- 保存保留位置、剩余格、行动任务、行军余量、冷却、组织度和军仓；旧档没有这些字段时仍按原驻地加载，组织默认完整。
- 运行中的地形变化使下一格不可通行时，小队停在原格等待改令，不重画地形、不填海。本次未改地图地形、海岸线、郡界、道路或用户存档。
