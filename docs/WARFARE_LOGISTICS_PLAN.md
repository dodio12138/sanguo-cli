# 战斗与补给改造企划

> 状态：企划稿（2026-10-14）。来源：汉庭企划讨论中用户对战斗、围城与补给的要求。与 `docs/HAN_COURT_PLAN.md` 配套。

## 0. 现状（改造起点）

| 环节 | 现在的做法 | 问题 |
|---|---|---|
| 野战 | `resolveFieldBattle` 一次结算：三个固定比例的回合，战力高者胜；败方士气 −15 后退到最近己方据点，无处可退则全军归零 | 胜负只看战力比，不看士气；无伤员、无老兵、无俘虏；「全军覆没」只在无路可退时发生 |
| 攻城 | 围困、强攻、地道、水攻等围法按旬结算；守方只有「出城突击」（袭扰，攻方损 4%）与「激励固守」 | 守方不能出城与攻方正面决战，也不能突围 |
| 野外补给 | 军团有随军军仓 `stores.food`；野外缺粮时直接从附近己方城（30 格内）把粮食「瞬移」进军仓 | 大军的粮道不存在，没法被截断，也看不到 |
| 转运 | 已有转运队列 `fiscalAccounts.shipments`：按陆路分段、有日程和途损，可指定送往某军团 | 只用于府库调拨，没接到野战军的补给上 |
| 联军 | 已有 `coalitions`：成员 AI 每月就近向目标进军 | 没有集结地和统一发动时间 |

## 1. 战斗：打到士气崩溃为止

### 1.1 分回合交战

一场野战按回合推进（每回合约半日，一日最多 4 回合；大战可跨日，次日续战）。每回合：

1. 双方按战力比给对方造成损失。现有的阵型、战术、地形、兵种、武将、正面宽度照常作用于战力。
2. 每支军团按本回合损失占本军的比例掉士气，此外还会因以下情况额外掉士气：
   - 侧翼被攻（被两个方向夹击）；
   - 主将阵亡或被俘；
   - 友军溃逃；
   - 军团断粮。
3. 士气跌破**溃散线**（默认 25，受将领统率与老兵比例影响）的军团溃逃，脱离战斗。
4. 一方全部溃逃或主动撤退，战斗结束。玩家可给军团设「撤退士气线」（如 40），到线即有序后撤，比溃逃损失小。

战报改为逐回合记录双方兵力、士气曲线和溃散原因。

### 1.2 伤亡构成

一次损失按比例拆成三部分（比例随兵种、地形、胜负变化）：

| 部分 | 去向 |
|---|---|
| **阵亡** | 永久损失 |
| **伤员** | 进入军团的 `wounded`，不参战、照常吃粮；驻在己方城中按日康复归队（城中有医、治安好则快），断粮时伤员死亡率上升 |
| **溃散** | 败方大量产生；一部分数日后回到最近的己方据点归建，其余流失；被追击时溃散兵成为俘虏 |

### 1.3 老兵

- 军团新增**老兵比例**（0–100%）。参战幸存者按战斗烈度转为老兵；补入新兵会稀释比例；伤员康复后保留老兵身份。
- 老兵显著提升战力（满老兵约 +30%）与溃散线抗性（溃散线下移），对长期征战的精兵有意义。
- 显示为精锐度四档：新募 / 成军 / 老练 / 百战。与现有「训练」（操练所得）分开，训练有上限，老兵只能打出来。

## 2. 追击、包围与俘虏

### 2.1 追击

胜方在敌军溃逃后可追击：追击强度看骑兵比例、剩余士气与疲劳；追击把溃散兵转为**俘虏**与额外阵亡。败方若是有序撤退（未溃散），追击收益大减。

### 2.2 包围歼灭

撤退时检查**退路**：相邻据点中，己方或中立、且没有敌军驻扎的方向。

- 没有退路（四面被占，或隘口被堵）：溃逃一方大部被俘或歼灭，主将被俘概率大增。
- 战斗中敌方从两个以上方向同时投入兵力：被夹击一方士气额外下跌。

这样「迂回切断退路」成为可以策划的战术。

### 2.3 俘虏处置

俘虏随胜方军团行动（吃粮、拖慢行军），到己方城后可以：

| 处置 | 结果 |
|---|---|
| **收编** | 逐日转为本方士兵，新兵、低士气，收编期间有哗变风险 |
| **释放** | 对方关系上升，本方民心与仁德声望上升 |
| **遣返换俘** | 外交交换，可换回被俘将领 |
| **坑杀** | 天下关系与民心大跌，不推荐 |

## 3. 攻城：守方的三种出城方式

围城窗口里守方的操作拆为：

| 操作 | 说明 |
|---|---|
| **突击袭扰**（现有） | 小股出城扰营，损攻方兵力和士气，不决战 |
| **出城迎战**（新增） | 守军主力出城，与围城军按野战模型正面交战。守方背城作战：溃散线下移，败退可退回城内，被追击损失小。胜则解围，败则城中兵力锐减 |
| **突围**（新增） | 选出一支小股部队（可带守将、家眷，都城则可带天子）向指定方向冲出包围 |

**突围的成败**取决于：
- 包围完整度：已有的 `siegeEncirclement` 加上该方向的攻方兵力；
- 突围部队规模：越小越隐蔽，越大越能硬冲；
- 骑兵比例、主将武力与统率；
- 夜色和地形。

结果有三档：
- **成功**：突围部队带着人员到达相邻己方据点。
- **折损**：部队大半损失，部分将领被俘。
- **失败**：部队覆没，人员被俘；天子落入攻方之手。

城破时未突围的守将按现有规则被俘或逃散。

## 4. 补给线：大军的粮要真的运过去

### 4.1 随军携粮与组织度

- 出征时玩家设定**携粮天数**（滑杆）。
- 每千人可轻松携带约 10 日口粮；超出部分拉长辎重队列，降低新数值**组织度**（0–100）并拖慢行军。
- 组织度低时，交战中阵型展开慢、溃散线上移、易遭伏击。
- 界面按兵力给出建议上限，超出时提示「建议设立粮道」。

### 4.2 小股部队

**轻装部队**（默认 3,000 人以下）不设粮道：
- 全靠携粮；
- 在敌境可以**就食**，取当地粮食，会降低当地治安、增加民怨；
- 行动自由，适合奇袭、袭扰。

### 4.3 粮道与运粮队

- 大军在野外不再瞬移补粮。当随军粮仓低于补给线阈值时，补给来源（后方粮仓或前进粮仓）派出**运粮队**。运粮队沿陆路、水路实际行进，复用现有转运队列，途中有损耗。
- 舆图新增**补给线**显示：
  - 每支野战军到其补给来源画一条线，线上标出在途运粮队；
  - 粮道被切断时线条变红。
- 运粮队可指派**护送**：抽调一支军团，或由补给来源城拨出护送兵。护送兵越多越不易被截。

### 4.4 前进粮仓

可在靠近前线的己方据点修建前进粮仓：
- 修建复用现有的工役／工程系统，需要粮食、工期和民夫；
- 建成后从后方分批运粮囤积，前线大军就近取用，缩短粮道。

### 4.5 袭扰粮道（新军事行动）

- **下令**：指派一支部队（骑兵、轻装为宜），针对敌方某段粮道或在途运粮队下令。
- **判定**：按护送兵力、侦察和地形判定能否截获。
- **成功**：缴获部分粮草归本军，其余焚毁；敌军断粮，士气、组织度下降。
- **断绝**：反复成功即「粮道断绝」，敌方大军须回撤或改道。
- **AI**：骑兵占优时会主动袭扰，大军出征时会配护送。

## 5. 汉庭相关

- 都城被围时，挟天子者可用「突围」带天子出城，突围成败决定天子归属（见汉庭企划第 9 节第 1 条）。
- 「联军攻势」：联军成员按集结地会师，到发动日期再同时进攻。会师中的各军共享补给规则，也会被袭扰粮道。

## 6. 数值与性能约束

- 战斗只在接敌时计算，回合数有上限；不在每日对全图做寻路。
- 运粮队按「军团 × 补给来源」合并，同一条粮道上同时最多一队在途。存档体积测试（现约 0.9 MB/年）不得明显上涨。
- 伤员、老兵、组织度、俘虏都是军团上的几个数，不新增大型数据结构。
- 新数值均写入 `game_rules.json`，便于调参。

## 7. 界面

- **军团详情**：
  - 兵员构成：健卒、伤员、老兵比例、俘虏；
  - 组织度、携粮天数；
  - 补给来源与在途运粮队；
  - 撤退士气线设置。
- **战报**：逐回合兵力与士气、溃散原因、追击与俘获、包围情况。
- **围城窗口**：突击袭扰、出城迎战、突围三个按钮，各附成功率估计；突围时选择人员与方向。
- **军事行动**：新增「袭扰粮道」「护送粮队」「修建前进粮仓」。
- **舆图**：补给线显示；新增或复用一个图层显示粮道与运粮队。

## 8. 分期与总顺序

| 阶段 | 内容 |
|---|---|
| **W1 战斗核心**（已完成） | 分回合交战、士气溃散与撤退线、伤亡三分、伤员康复、老兵比例；战报改版 |
| **W2 追击与包围**（已完成） | 追击、退路判定与包围歼灭、俘虏与收编／释放／换俘 |
| **W3 攻城扩展** | 出城迎战、突围（守将、家眷、天子）、城破处置 |
| **W4 实运补给** | 大军野外补给改走运粮队；携粮天数与组织度；轻装部队与就食；补给线显示 |
| **W5 粮道战** | 前进粮仓、护送、袭扰粮道、AI 对应 |

**建议的总顺序**（与汉庭企划交错推进）：

1. 汉庭 P0、P1：数据骨架、程序窗口、两张舆图、城市页州郡县分栏。这部分独立、能最快看到效果。
2. W1、W2：战斗核心与追击包围。
3. W3：攻城扩展，天子突围要用到它。
4. 汉庭 P2：册封、安抚免战、任免太守、请封抗诏。
5. W4、W5：实运补给与粮道战。
6. 汉庭 P3、P4：讨逆、联军攻势、九锡与称帝、平衡调参。

每一步都附单元测试和浏览器核对，并跑长局模拟，确认 AI 对局不崩、存档体积可控。

## 9. 实施记录

- **W1（2026-10-14）**：`js/core/engine/battle.js`，数值见 `game_rules.json` 的 `battle` 段。
  - 每回合按双方战力比互损（单回合封顶 35%），士气按本回合损失比例与兵力悬殊下跌；溃散线 25，统率高、老兵多则下移；撤退线默认随战术（猛攻 0、均衡 30、持重 40），改编窗口可设。
  - 溃散追加 10% 损失（多为溃散兵），有序后撤只追加 3%；双方同时崩溃时，离溃散线远的一方站住。打满 8 合仍未分出胜负为「相持」，攻方收兵。
  - 损失按阵亡 30%、伤员 45%、溃散 25% 拆分；伤员吃粮、计入补员目标，驻己方城按治安每日约 1.5–4.5% 康复，野外慢愈且有死亡，断粮死亡更多；溃散兵四成随后归建。
  - 老兵以人数记在军团上：减员按比例带走，补新兵自然稀释；满老兵战力约 +30%。新开局按训练度给初始老兵，新编军团为 0。
  - 一年 AI 推演：一边倒的战斗 1–2 合，势均 3 合以上。
- **W2（2026-10-14）**：追击、退路与围歼、俘虏，数值见 `game_rules.json` 的 `battle`（追击、围歼）与 `prisoners` 段。
  - 追击强度 = (0.15 + 骑兵比例 × 0.6) × 胜方士气，上限 0.6；溃散兵按强度的八成被俘，残部再追损一部分（半亡半俘）。有序后撤者只受三成追击。
  - 退路：攻方先回来处，否则（及守方）退往相邻的己方或盟友据点；有交战敌军驻扎的方向不可退。无路可退即被围歼：六成被俘、伤员全俘，主将六成概率被俘。
  - 俘虏按来源势力记数，随胜军押解（口粮按半计、拖慢行军，野外每日逃 1%），败军押解的俘虏趁乱逃散。到己方城入营关押，城页「战俘营」可收编（逐日 4% 入守军）、释放、遣返换俘（每千人换回一名被俘将领）、坑杀。看守少于战俘时逃散并扰动治安；城池易主时新主本方被俘者获释。AI 城一律收编。
  - 「两个方向夹击额外掉士气」尚未做，等补给线（W4）有了来向数据再补。
