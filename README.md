# 九州策：终端三国

一个受早期《三国志》与经典策略游戏启发的网页策略游戏。1.0.0 已形成从剧本选择、旬度经营和战争到统一/败亡的完整单局闭环。

## 启动

macOS 下双击项目根目录的 `启动游戏.command`，它会同时启动本地网页服务和 AI 网关、自动连接网关并打开默认浏览器。关闭启动器终端窗口或按 `Ctrl+C` 会同时停止由启动器启动的服务；不需要安装 npm 依赖。

如需接入 DeepSeek AI，先将项目根目录 `.env` 中的 `AI_API_KEY=` 填入自己的密钥。启动器会读取该配置并拉起网关；密钥仅供本地网关读取，网页静态服务器禁止访问 `.env` 文件。详细配置见 [AI 接入说明](docs/AI_API.md)。

也可在项目目录手动启动：

```bash
node tools/start-game.mjs
```

启动器会优先使用 `8080`–`8090`，如均被占用则自动申请系统空闲端口；AI 网关端口由 `.env` 的 `JIUZHOU_AI_PORT` 决定，游戏打开时自动连接。存档同时写入浏览器和项目内被忽略的 `.local/saves.json`，因此下次启动即使端口变化也能恢复。若 API 密钥未配置或网关启动失败，游戏仍可手动游玩。只想检查资源能否正常提供，可运行 `node tools/start-game.mjs --smoke-test`。

## 当前内容

- 终端 / CLI 风格的响应式界面
- 40 × 32 汉末主要战略区网格地图，含 75 个城市、港口、关隘与渡津，以及 51 个郡国、253 个县治；支持地形、势力、州域、郡域、补给五种图层
- 史籍郡国人口按郡治、重要县和普通县精确分配到 253 县；县域编户、农商、治安、税粮、自然增长与募兵消耗均进入旬结算
- 郡县两级治理：郡守、太守与劝农、市曹、功曹、户曹、城防、兵曹、督练官均可任命；空缺由能力 45 的普通官员代理
- 农业、商业、治安、人口与城防按官员能力逐旬自然发展，原内政按钮改为六旬督查加速；兼任多职会降低每项效率
- 城池与县治选择、势力与州郡概览、图例、缩放；郡域图按缩放层级显示郡治、重要县与全部县名，并裁剪视角外网格和标记
- 玩家命令输入与待执行命令队列
- “结束本旬”推进十天并按阶段结算、归档旬报
- 仿 P 社的数据目录和 Mod 覆盖约定
- 内置数据/Mod 调试台：加载顺序、覆盖冲突、剧本校验与 JSON 导出
- 正式 JSON Schema、JSON Path 错误定位、Mod 启停与冲突路径报告
- v1—v15 旧存档自动迁移至当前 v16；每旬自动保存、保留上一份备份，调试台支持存档 JSON 导入导出
- 可重建的完整离线数据镜像，直接打开也可读取官渡 565 名完整战局人物
- 数据驱动的历史/随机事件、条件触发、事件抉择与 Mod 扩展接口
- 人物性格、相性、派系、亲缘、动态忠诚、举荐与叛离系统
- 全势力外交关系网、AI 宣战议和、联盟、共同敌人与附庸体系
- 主副将、兵种适性、特技、地形、训练、士气和补给共同决定的战力模型
- 数据驱动的阵型、战术、兵种克制与接战/鏖战/决胜分轮战报
- 战意蓄积与火计、突击、齐射等军团战法，独立战役档案可回看分轮伤亡
- 市集、农庄、兵营、学宫、驿站及城市建筑槽，产出按旬度结算
- 军团负责人、辖区与自动委任，科技树和各势力专属特性
- 玩家主导的联军讨伐、盟友参战与每三旬协同进军
- HTTP 模式下从正式 JSON 数据目录加载，并校验地图与引用
- 城市详情、武将/军团概览和快捷命令
- 浏览器本地存读档与旬报历史
- 城市路网逐旬行军、补给、确定性事件和基础外交关系
- 渡河额外消耗、急行军、扎营、伏击/撤退姿态及最小城市攻防结算
- 步兵、骑兵、弓兵编制，主将/副将/参军军职槽，以及按目标逐旬自动训练和补员
- 人才搜索/登庸、人物调任赏罚、宝物归属、官职、军师和继承人
- 治安、人口、城防、征税、粮食交易、税率及城市型随机事件
- 城市建筑、仓储、水利、动态道路、本地金粮、运输、民夫和补给路线
- 战争与条约状态、外交交换、分级情报、反间谍和概率型谋略行动
- 军政、内治、外交、人物档案窗口
- AI/MCP 工具契约与只生成命令、不直接改状态的权限边界
- 可选本地 AI 网关、游戏内连接面板、辅助建议/自动托管，以及 MCP JSON-RPC 工具入口
- 设置中可分别启用本方 AI 史官与全局 AI 史官；全局史官从诸侯行动、战事和天下大势日志中择取少数要事，启用或连接后会补查最近一年的已结月份，战斗可作有限文学化补景；两卷均随本地存档保存，手动游玩时也可执笔
- 主界面按“我方 / 所选 / 群雄”与“下达命令 / 本旬军令 / 战局态势”分组切换，地图保持中央主视区，减少侧栏信息堆叠
- 路网化补给传播、敌军截断与自动恢复、运输容量和军团续航评估
- 190 反董、200 官渡、208 赤壁的势力背景、阶段目标与多阶段历史抉择
- 16 类、105 项统一命令注册表和可浏览命令簿；玩家与 AI 使用相同命令 ID
- 105 项命令均有规则路由与结果事件，无“尚在规划”占位命令
- 命令簿为人物、城市、军团、势力、宝物、数量及政策提供可视化选择器，自然语言仅作补充入口
- 重复命令和同一人物的多项个人行动会在加入队列时拒绝
- 固定全屏工作台布局，页面本身不滚动，长内容仅在各自面板内滚动
- 诸侯战略 AI：辖区发展、军团规模控制、自动补员、守城驰援、协同战力评估与目标选择
- 多旬攻城：城防破坏、守军消耗、围城补给、自动撤围、破城退却与占领损失
- 飞地与孤城围困：连续领土判定、粮道封锁、城内存粮消耗、饥饿减员和士气归零投降
- 道路野战与战后系统：拦截、伏击、渡河惩罚、败退、武将负伤/被俘、登庸与释放
- 全势力经济：季节收获、税收、军粮、人口变化、缺粮逃散，以及受预算约束的诸侯发展与扩军
- 三个可玩剧本：190年反董卓联合、200年官渡风云、208年赤壁之战，均可选择对应势力开局
- 无强制剧本期限，统一天下或失去全部据点时结束游戏
- 长期战役平衡模拟器：可选择 190、200、208 剧本，批量推进数百旬，检查资源、引用和军团编制不变量，并复测三档难度
- 数据驱动的势力战略性格，以及针对占据近半天下势力的“共讨霸主”目标评估
- 战略情报面板：天下占比、霸主提示、前线压力、分级敌军意图和近期格局变化
- 战争计划：按军事目标计算军团集结路线、补给预算、攻城旬数、战力前景与来袭预警
- 战争计划辅助执行：一键生成前线集结或正式进攻命令，仍由玩家确认并在旬末统一结算
- 防御计划按来袭时间和兵力缺口生成驰援命令；AI 军师支持玩家战略意图与六轮决策记忆

1.0.0 的验收命令和已知范围见 [docs/RELEASE.md](docs/RELEASE.md)。

详细设计与后续路线见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。直接双击时使用内嵌数据；通过静态服务器运行时使用 `game/data/`，并读取 `mods/registry.json`。

数据校验、Mod 制作和离线镜像生成见 [docs/MODDING.md](docs/MODDING.md)。

开局也可选择“观察者”：不接管势力，默认每 3 秒自动推进一旬，并可暂停、单步或切换为 1/5 秒速度；观察模式公开全图军情，直到一方统一天下。

## 目录

```text
sanguo-cli/
├── index.html
├── css/
├── js/
│   ├── data/                 # 可直接由浏览器加载的原型数据

│   └── ui/                   # 地图和界面
├── game/
│   ├── data/common/          # 规则定义
│   ├── data/history/         # 剧本开局状态

```
